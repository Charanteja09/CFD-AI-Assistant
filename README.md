# CFD AI Assistant

AI-assisted CFD simulation analysis.

## Features

- Upload CFD data
- Analyze velocity and pressure
- Calculate flow rate
- Calculate Reynolds number
- Identify flow regime
- Generate velocity/pressure graphs
- Generate AI-based engineering summary
- Generate PDF report

## Tech Stack

- Python
- FastAPI
- Matplotlib
- ReportLab
- Ollama

## Project Structure

- Backend - FastAPI backend and analysis logic
- Data - Sample CFD data
- generated - Generated graphs and reports
